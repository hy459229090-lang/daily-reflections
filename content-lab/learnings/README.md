# 公开经验

当前还没有经过验证并获准公开的经验条目。此目录不预填“爆款规律”或示范性成果。

实际实验先在核对过访问权限的工作区复盘；达到公开条件后，再从 [学习卡](../templates/learning.md) 整理一个去标识的聚合版本。

## 每条经验至少说明

- 命题、平台、受众、内容形式与适用条件。
- 状态：待检验 / 暂可复用 / 有反证 / 已撤回。
- 实验数量、观察窗口、可比范围与缺失情况。
- 观察事实与解释，分开书写。
- 反例、替代解释、不适用条件及最后复核日期。

“暂可复用”只是有限条件下的工作判断，不代表算法规则、因果结论或效果保证。新证据不支持时应更新状态，保留修订原因。

## 公开前检查

1. 确认可公开的具体内容与范围。
2. 只保留聚合概括，不附本人单条作品指标、真实实验私密引用、未发布观点或后台截图。
3. 删除账号信息、个人身份线索和可反推个人或作品的组合细节。
4. 核对来源使用权，避免复制第三方全文、完整脚本或评论资料。
5. 同时检查文件、提交消息、PR、Issue、日志和产物。

建议文件名为 YYYY-MM-DD-简短主题.md；没有合格经验时保持目录为空即可。
