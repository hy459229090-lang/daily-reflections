# 指标与比较口径

## 记录原则

保留平台实际显示的名称、单位和采样时间。不同平台的同名字段未必同义，先核对再比较。

每个可选指标使用如下字段：

- value：数字或 null。只有明确观察到零才填 0。
- source_label：平台实际字段名称；人工计数时写清标准。
- source_type：creator_analytics / public_display / manual_count / user_report。
- displayed_value：界面原文，便于保存“1.2 万”一类显示值。
- unit：次、个、秒、% 等实际单位，不能混用百分数和小数。
- precision：exact / rounded / estimated；缺失值可为 null。
- unavailable_reason：缺失、不可见、尚未到观察窗口、未授权读取等原因；可用时为空。

“1.2 万”可以换算为约 12000 用于描述，但必须保留原文并标 rounded，不能视为精确计数。估算要另写方法，不从未知数据补数。

## 原始指标候选

只记录数据源实际提供的项目：

| 字段 | 含义与限制 |
| --- | --- |
| views | 实际显示的播放 / 阅读指标；记录原名称，不假定两者一致 |
| impressions | 实际显示的曝光指标，不与播放混用 |
| likes | 点赞数，不能替代播放量 |
| saves | 收藏数 |
| comments | 评论数；不自动等于独立反馈人数 |
| shares | 分享数 |
| average_watch_seconds | 平台提供的平均观看秒数 |
| completion_rate | 平台提供的完播率，注明单位及可见定义 |
| attributed_follows | 数据源可归因到该内容的新增关注；无法归因就记 null |
| qualified_feedback_count | 按事前标准人工去重的有效反馈人数 |
| attributed_trial_count | 有实际体验证据且能合理对应到该内容的体验人数 |

平台不提供或当前看不到的指标记 null。不能从公开互动倒推出曝光、留存、转粉或算法偏好。

## 反馈与体验

qualified_feedback_count 的事前标准：至少包含具体问题、使用场景、尝试结果或明确试用意愿之一。纯表情和泛泛夸赞不计；同一人的重复反馈只计一次。分析记录只保留去标识摘要，不把身份资料写入公开仓库。

attributed_trial_count 只采用已合法取得的实际产品体验证据。看过内容、发表评论、表示愿意或完成意向报名，都不等于已经体验。不能合理对应到某条内容时，写明“归因未知”，不强行分配。

## 派生率

仅在同平台、同作品、同一快照中，分子分母口径相容、分母可用且大于零时计算。例如：

收藏率 = 收藏数 / 对应的播放或阅读数。

必须写清所用分母、公式、单位与来源。分母为零、未知或口径不相容时，派生率记 null。不要把曝光口径的率与播放口径的率直接比较，也不跨平台直接比较胜负。

## 快照

每次快照保存：

- published_at：真实发布时间，带时区。
- captured_at：实际采样时间，带时区。
- elapsed_hours：两者间实际经过的小时数。
- checkpoint：计划检查点 24h / 72h / 7d。
- timing_note：准时、延迟、补采或缺失说明。
- data_source：官方后台 / 官方导出或截图 / 公开页面 / 人工记录及出处。
- metrics：上面的指标对象，仅填可获得项目。

checkpoint 是计划标签，不能替代实际时间。延迟快照要保留偏差；不同观察窗口的数据不能当作同窗口实验比较。未发布作品不填结果。

## 基线与判断

优先比较本人同平台、同形式、同观察窗口的历史作品。可先积累 5—10 条作为初步基线；不足时只给探索性描述。这是操作建议，不是统计充分性的保证。

每次展示样本数、取样规则、缺失情况及关键差异。中位数有助于描述，也不能消除选题、发布时间、账号状态或分发等混杂因素。

主要指标在发布前按目标选定：

- 实用教程：可考虑收藏率，但先确认分母可得。
- 演示视频：可考虑完播率，但仅限后台可见。
- 需求理解：可考虑有效反馈。
- 产品获客：可考虑实际体验，并说明归因限制。

没有可用数据源时提前换成能记录的指标，不能等结果出现后挑最漂亮的一项。主要指标、辅助指标与风险观察项分别保存。

## 不能从这些数据直接得出的结论

一次高互动不证明某个表达导致增长；几个案例不证明平台算法偏好；互动也不证明产品已满足市场需求。保留替代解释、失败样本和反例，结论只在已有证据的范围内使用。
