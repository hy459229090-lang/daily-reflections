# 每日复盘

记录当天发生的事、真实的感悟和下一步想做的事。长短不限，不为凑齐格式而写。

## 更新方式

- 每晚交流后整理成草稿，确认内容后再发布。
- 按北京时间的日期归档，每天一篇，也可以继续补充和修订。
- 模板只是参考，可按当天的内容增减。

## 归档方式

复盘保存在 `journal/YYYY/MM/YYYY-MM-DD.md`，其中日期对应复盘的那一天。

- [复盘归档](journal/)
- [空白模板](templates/daily.md)：事实、感悟、下一步

## 公开前检查

这个仓库是公开的。发布前检查是否包含联系方式、账号信息、工作机密或他人隐私；不适合公开的内容不放进仓库。
